# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately through GitHub's **Report a vulnerability** feature when available. If that option is unavailable, open a minimal public issue without including secrets, credentials, personal data, or an exploit payload; request a private contact channel from the maintainer.

Do not commit API keys, ad-network credentials, private tokens, or personal information to this repository.

## Scope

Toolinger is primarily a client-side static web application. User files and tool inputs are intended to remain in the browser; optional AI assets load from third-party providers under their own policies. This build has no active advertising or analytics scripts.
